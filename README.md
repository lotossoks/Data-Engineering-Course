# Data Engineering Course

## Как запустить домашку 1

Нужен установленный и запущенный Docker с Docker Compose. Из корня репозитория перейдите в папку проекта:

```bash
cd "Домашка 1/store_hse"
```

Перед сдачей выполните проверку с нуля, как при проверке преподавателем. Команда `down -v` удаляет Docker-тома этого учебного проекта вместе с данными; следующий запуск создаёт чистые базы и повторно загружает исходные данные.

```bash
docker compose down -v && docker compose up -d
docker compose logs -f loader
```

Дождитесь строки «Готово» от загрузчика. Затем нажмите `Ctrl+C`, чтобы выйти из просмотра логов, и установите пакеты dbt перед сборкой:

```bash
docker compose run --rm dbt deps
docker compose run --rm dbt build
```

Ожидается `ERROR=0`. Допустим известный `WARN` теста `assert_no_overpayment`: у заказа 113 два успешных списания по 200 при стоимости заказа 200. Исходные данные намеренно сохранены без исправлений.

Описание моделей, хранения, тестов и граф зависимостей — в [README домашки](<Домашка 1/store_hse/README.md>).
